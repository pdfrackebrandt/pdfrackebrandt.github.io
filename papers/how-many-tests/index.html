How many tests was it really?

Pedro F. Rackebrandt, with Sebastian Winzker

Why does this matter? When you test thousands of trading rules, the best one will look good by chance. Cluster corrections that group similar rules can make noise look significant by undercounting the tests. A block bootstrap on the real grid keeps the correlations and shows the safer hurdle is the full nominal count.

We resample the 2,825 moving-average rules together. On the DAX the effective independent tests are about 1,400. Even spread-out correlation barely lowers that number; only rules bunched in blocks do. The best rule still fails the hurdle on the DAX.

How to read the figure

The curve is the expected maximum Sharpe ratio if every rule is noise. It grows like the square root of log N, so only the order of magnitude of N matters. The buttons read the hurdle at the cluster, effective, and nominal counts.

Software that clusters similar moving averages reports N = 2. That point sits far below the measured hurdle. The measured effective count is about 1,400. Using the raw grid of 2,825 overstates the hurdle by 6 percent.

On the DAX the best rule clears the mean of the noise maximum and still fails the 95 percent band.
