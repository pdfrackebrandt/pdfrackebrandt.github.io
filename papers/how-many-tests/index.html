How many tests was it really?

Pedro F. Rackebrandt, with Sebastian Winzker

How high the bar for a backtested trading rule should be once you count every rule you tried.

Draft on request
How to read the figure

The curve is the expected maximum Sharpe ratio if every rule is noise. It grows like the square root of log N, so only the order of magnitude of N matters. The buttons read the hurdle at the cluster, effective, and nominal counts.

Software that clusters similar moving averages reports N = 2. That point sits far below the measured hurdle. The measured effective count is about 1,400. Using the raw grid of 2,825 overstates the hurdle by 6 percent.

On the DAX the best rule clears the mean of the noise maximum and still fails the 95 percent band.

The question

Every parameter search is a multiple test. The best of many noisy rules looks good by chance, so the bar it must clear rises with the number of rules tried. A grid of moving average rules holds thousands of settings, and neighbouring settings trade almost alike. How many independent tests does such a grid represent, and what does that count do to the bar?

The hurdle

Bailey and López de Prado (2014) give the Sharpe ratio that the best of NNN independent noise strategies reaches on average:

SR^0=E[max⁡nSR^n]≈σSR[(1−γ) Φ−1(1−1N)+γ Φ−1(1−1Ne)]\begin{aligned} \widehat{SR}_0 = \mathrm{E}\Big[\max_n \widehat{SR}_n\Big] \approx \sigma_{SR}\Big[&(1-\gamma)\,\Phi^{-1}\Big(1-\frac{1}{N}\Big) \\ &+\gamma\,\Phi^{-1}\Big(1-\frac{1}{N e}\Big)\Big] \end{aligned}SR0​=E[nmax​SRn​]≈σSR​[​(1−γ)Φ−1(1−N1​)+γΦ−1(1−Ne1​)]​

Here SR^n\widehat{SR}_nSRn​ is the estimated Sharpe ratio of trial nnn, σSR\sigma_{SR}σSR​ the spread of those estimates across trials, Φ−1\Phi^{-1}Φ−1 the inverse of the standard normal distribution function, γ≈0.5772\gamma \approx 0.5772γ≈0.5772 the Euler Mascheroni constant and eee Euler's number. The hurdle grows like ln⁡N\sqrt{\ln N}lnN​, so only the order of magnitude of NNN matters.

The deflated Sharpe ratio is the probability that the chosen rule's true Sharpe ratio beats that hurdle:

DSR=Φ ⁣((SR^−SR^0)T−11−S^ SR^+K^−14 SR^2)\mathrm{DSR} = \Phi\!\left(\frac{\big(\widehat{SR}-\widehat{SR}_0\big)\sqrt{T-1}}{\sqrt{1-\hat{S}\,\widehat{SR}+\dfrac{\hat{K}-1}{4}\,\widehat{SR}^{2}}}\right)DSR=Φ​1−S^SR+4K^−1​SR2​(SR−SR0​)T−1​​​

SR^\widehat{SR}SR is the chosen rule's Sharpe ratio, TTT the number of returns, S^\hat{S}S^ their skewness and K^\hat{K}K^ their kurtosis (3 for normal returns). The denominator is the estimation error of a Sharpe ratio; fat tails and negative skew widen it.

Counting the tests

We run a stationary block bootstrap on the full grid of 2,825 moving average rules. Each replicate draws the same trading days for every rule, in blocks of random length with mean ten days, so the correlation between rules survives. The best Sharpe ratio in each replicate gives the null distribution of the maximum. The effective number of tests NeffN_{\text{eff}}Neff​ is the count that makes the formula return the bootstrap's expected maximum:

E∗[max⁡nSR^n]=σSR[(1−γ) Φ−1(1−1Neff)+γ Φ−1(1−1Neff e)]\begin{aligned} \mathrm{E}^{*}\Big[\max_n \widehat{SR}_n\Big] = \sigma_{SR}\Big[&(1-\gamma)\,\Phi^{-1}\Big(1-\frac{1}{N_{\text{eff}}}\Big) \\ &+\gamma\,\Phi^{-1}\Big(1-\frac{1}{N_{\text{eff}}\,e}\Big)\Big] \end{aligned}E∗[nmax​SRn​]=σSR​[​(1−γ)Φ−1(1−Neff​1​)+γΦ−1(1−Neff​e1​)]​

E∗\mathrm{E}^{*}E∗ is the average over bootstrap replicates. The right side rises with NeffN_{\text{eff}}Neff​, so one value solves it.

The result

On the DAX, NeffN_{\text{eff}}Neff​ is about 1,400. Software that clusters similar moving averages reports N=2N = 2N=2. Cluster corrections of this kind cut the hurdle by as much as 84 percent and call noise significant. The raw count of 2,825 overstates it by 6 percent.

Why so little shrinkage? A correlation shared evenly by all rules moves the whole grid up and down together. It shrinks the expected maximum and the spread σSR\sigma_{SR}σSR​ by the same factor, so the formula still needs the full NNN. Only block structure lowers NeffN_{\text{eff}}Neff​: rules inside a tight block act as one. Of the eigenvalue corrections, only Gao (2008) stays close.

What it means

The hurdle grows so slowly in NNN that counting too many trials costs little, while counting too few costs a lot. The block bootstrap on the real grid shows the nominal count is the safe one.
